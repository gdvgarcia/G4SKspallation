				   ***\\ ANALYSIS MACROS //***

	These macros are made to be used with the Root data analysis framework 
	and they target the root file produced by the G4SKspallation2_v3 simulation. 
	If you change the name of the root file produced from the simulation, 
	remember to change the name of the opened file in the macros.

	The files produced from these macros are made for comparisons with Li and Beacom
	articles. So its main purpose is to study the passage of muons through water tanks.
